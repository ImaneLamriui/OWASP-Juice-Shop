# Política de seguridad

Si encuentras una vulnerabilidad en este repo o en las pruebas descritas, por favor no la publiques en público. Sigue estos pasos:

1. Crea un issue privado o contacta al mantenedor por correo (si está disponible).  
2. Incluye una descripción, pasos para reproducir, y artefactos sanitizados (tokens reemplazados por `REDACTED`).  
3. No compartas datos reales de usuarios ni accesos no autorizados.

Este repo es para aprendizaje y pruebas en entornos locales. No realices pruebas en sistemas que no controles.
