# Contribuir

¡Gracias por querer contribuir! Para mantener este proyecto seguro y útil, por favor sigue estas pautas:

## Antes de contribuir
- Lee el `README.md` y la `poc_sqli.md`.
- No envíes credenciales, tokens, HARs sin sanitizar ni dumps de bases de datos.

## Cómo contribuir
1. Haz un fork del repositorio.  
2. Crea una rama con un nombre descriptivo: `feature/mi-mejora` o `fix/typo`.  
3. Haz commits pequeños y con mensajes claros.  
4. Empuja tu rama y abre un Pull Request (PR) describiendo los cambios.

## Pull Requests
- Incluye una descripción clara del cambio y por qué es útil.
- Si añades código o pruebas, asegúrate de que sean no destructivas y que funcionen en entornos de prueba.
- Si tu PR incluye scripts que ejecuten comandos, añade una explicación detallada y riesgos.

## Issues
- Usa las plantillas de issues y añade pasos reproducibles.
- No publiques información sensible en issues públicos.

## Política de revisión
- TODO PR será revisado por al menos 1 maintainer.
- Los PRs que modifiquen scripts de automatización o despliegue requieren revisión adicional.

Gracias por colaborar. 🙌
